Connexion TikTok

Lecture de l’adresse…

  1. revenez dans Quiz TikTok Studio, onglet Dashboard TikTok ;
  2. collez le code dans le champ « Adresse de retour, ou code » ;
  3. cliquez sur Terminer la connexion.

Vous pouvez aussi copier l’adresse complète de la barre d’adresse ci-dessus et la coller telle quelle : l’application sait en extraire le code.
